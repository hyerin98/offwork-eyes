# OffWork Eyes

퇴근 시간을 입력하면 퇴근까지 몇 분 남았는지 알려주는 데스크톱 위젯입니다.
눈동자가 마우스 커서를 따라 움직입니다. Windows와 macOS에서 동작합니다.

## 사용 방법

| 동작 | 방법 |
|---|---|
| 설정 패널 열기/닫기 | 캐릭터나 말풍선을 클릭 |
| 위치 이동 | 캐릭터나 말풍선을 드래그 |
| 빠른 메뉴 | 캐릭터를 우클릭하거나, 트레이(메뉴 막대) 아이콘을 클릭 |
| 종료 | 빠른 메뉴 → 종료 |

설정 패널에서 바꿀 수 있는 항목은 다음과 같습니다.

- 퇴근 시간
- 몸 색상: 기본 색상 7가지, 색상 선택기, 스포이드(화면의 아무 곳에서나 색 가져오기), HEX 값 직접 입력
- 표정 12가지: 기본, 졸림, 화남, 시큰둥, 곁눈질, 놀람, 설렘, 멍, 의욕, 월급날, 회의중, 야근
- 눈동자: 색상(몸 색상과 같은 방식), 크기
- 위젯 크기, 항상 위에 표시, 컴퓨터를 켤 때 자동 실행

캐릭터가 아닌 투명한 영역은 클릭이 그대로 뒤쪽 창으로 전달됩니다.

## 설치 안내 (배포받은 사람용)

[최신 Release](https://github.com/hyerin98/offwork-eyes/releases/latest)의 **Assets**에서 파일을 받습니다.

### Windows

두 가지 파일 중 하나를 받으면 됩니다.

- `OffWork-Eyes-Setup-<버전>.exe`: 더블클릭하면 바로 설치되고 실행됩니다. 시작 메뉴에 등록되고, 제어판에서 제거할 수 있습니다.
- `OffWork-Eyes-Portable-<버전>.exe`: 설치 없이 더블클릭만 하면 실행됩니다.

처음 실행할 때 "Windows의 PC 보호" 화면이 나오면 **추가 정보 → 실행**을 누릅니다.

### macOS

**터미널**을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누르면, 최신 버전을 내려받아 설치하고 실행까지 합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/hyerin98/offwork-eyes/main/install-mac.sh | bash
```

앱에 Apple 개발자 서명이 없어서, 브라우저로 내려받으면 macOS가 "손상되었다"며 실행을 막습니다.
터미널(`curl`)로 내려받은 파일에는 이 차단 표시가 붙지 않기 때문에 바로 열립니다.
같은 명령을 다시 실행하면 최신 버전으로 업데이트됩니다.

터미널 없이 설치하려면 아래 순서를 따릅니다.

1. `OffWork-Eyes-<버전>-mac.dmg`를 열고, 앱을 **응용 프로그램(Applications)** 폴더로 드래그합니다.
   (zip 파일을 받았다면 더블클릭해서 압축을 풀고 같은 방법으로 옮깁니다.)
2. 앱을 실행합니다. "확인할 수 없음" 경고가 나오면 **완료**를 누릅니다.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 이동해서, 아래쪽에 있는 **그래도 열기**를 누릅니다.
4. "손상되었기 때문에 열 수 없습니다"라는 메시지가 나오면, 터미널에서 아래 명령을 실행한 뒤 다시 엽니다.

   ```bash
   xattr -cr "/Applications/OffWork Eyes.app"
   ```

앱은 Dock에 표시되지 않고, 화면 위쪽 메뉴 막대에 눈 모양 아이콘으로 표시됩니다.

## 업데이트

앱이 켜져 있으면 시작 후 15초, 그 뒤로 6시간마다 새 버전이 있는지 확인합니다.
새 버전이 있으면 말풍선 모서리에 주황색 점이 생기고, 설정 패널 맨 위에 안내가 표시됩니다.

| 설치 방식 | 업데이트 방식 |
|---|---|
| Windows 설치형 | 백그라운드에서 자동으로 내려받습니다. 패널에서 **재시작**을 누르거나, 다음에 앱을 종료할 때 설치됩니다. |
| Mac | 패널에서 **업데이트**를 누르면 설치 스크립트가 최신 버전을 설치하고 앱을 다시 엽니다. |
| Windows Portable | 패널에서 **받으러 가기**를 누르면 다운로드 페이지가 열립니다. |

v1.0.2 이하 버전에는 업데이트 확인 기능이 없으므로, 한 번은 직접 새로 설치해야 합니다.

## 개발

```bash
npm install
npm start          # 개발 모드 실행
npm run icons      # 아이콘 PNG 다시 생성 (scripts/make-icons.js)
npm run dist:win   # Windows 설치 파일 + 단일 실행 파일 → dist/
npm run dist:mac   # macOS dmg + zip (Mac에서만 가능)
```

### 새 버전 배포하기

태그를 푸시하면 GitHub Actions가 Windows와 Mac 파일을 빌드하고, Release 페이지에 설치 안내와 함께 자동으로 올립니다.

```bash
npm version 1.0.2 --no-git-tag-version
```

```bash
git commit -am "chore: 1.0.2 버전으로 변경"
```

```bash
git tag v1.0.2
```

```bash
git push origin main v1.0.2
```

- 태그 이름은 `package.json`의 `version`과 같아야 합니다. 다르면 빌드가 실패합니다.
- 사람들에게는 `https://github.com/hyerin98/offwork-eyes/releases/latest` 링크만 공유하면 됩니다.
- Release 본문에 들어가는 설치 안내는 `.github/release-notes.md`에서 수정합니다.
- 배포하지 않고 빌드만 확인하려면 **Actions → build → Run workflow**를 실행합니다. 결과물은 Artifacts에서 내려받을 수 있습니다.

macOS용 파일은 Mac에서만 만들 수 있으므로, Mac 빌드는 GitHub Actions에서 진행합니다.

### 경로 길이 문제 (Windows)

프로젝트 폴더 경로가 너무 길면 NSIS 설치 파일을 만드는 단계에서 `could not open file` 오류가 납니다.
`C:\dev\offwork-eyes`처럼 짧은 경로에서 빌드하면 해결됩니다.

### 리소스 최적화

- GPU 가속을 꺼서 GPU 프로세스 메모리를 줄였습니다. 작은 위젯이라 소프트웨어 렌더링으로 충분합니다.
- 커서 위치는 움직일 때만 초당 30회 확인하고, 멈춰 있으면 초당 4회까지 줄입니다. 위치가 바뀐 경우에만 화면을 갱신합니다.
- 남은 시간은 매초가 아니라 표시되는 분이 바뀌는 순간에만 다시 계산합니다.
- 반복되는 CSS 애니메이션은 쓰지 않고, 깜빡임과 점프는 한 번씩만 재생합니다.
- 화면이 잠기거나 절전 모드에 들어가면 커서 추적을 멈춥니다.
- 배포 파일에는 한국어와 영어 언어 팩만 포함합니다.
